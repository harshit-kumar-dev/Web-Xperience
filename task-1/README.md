# 🌐 Task 1: The Experience | Premium Portal

A sophisticated entry portal featuring a quad-quadrant interactive landing page. It utilizes architectural imagery and smooth, cinema-like transitions to establish a powerful web presence.

## 🚀 Live Demo
[webxperience1.netlify.app](https://webxperience1.netlify.app/)

## ✨ Unique Features
- **Dual-State Image Hover:** Interactive visual feedback on user engagement.
- **GSAP Entrance Sequence:** A meticulously timed, animated introduction.
- **Dynamic Text Overlays:** Clipped typography that interacts with the background.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- GSAP
