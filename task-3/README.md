# 🎧 Task 3: AURA PRO | Pure CSS 3D

A groundbreaking scroll-driven storytelling experience for the "AURA PRO" earbuds. The earbud case is modeled entirely in **Pure CSS 3D**, demonstrating the power of native web features without reliance on external 3D rendering engines like Three.js.

## 🚀 Live Demo
[webxperience3.netlify.app](https://webxperience3.netlify.app/)

## ✨ Unique Features
- **Scroll-Triggered 3D:** The earbud case naturally opens and reveals its contents as the user scrolls.
- **Complex CSS Transforms:** Intricate use of CSS 3D (faces, hinges, interior wells) to create a lifelike object.
- **Immersive Narrative:** Vertical scrolling dictates the pace of the visual story.

## 🛠️ Tech Stack
- HTML5
- CSS 3D Transforms
- GSAP
- ScrollTrigger
