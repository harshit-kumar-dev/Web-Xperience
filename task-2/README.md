# ⚡ Task 2: FORGE | Elite Gym Gear

An aggressive, elite-grade fitness e-market interface. Designed with high-contrast aesthetics, "The Forge" brand identity emphasizes peak performance and premium quality.

## 🚀 Live Demo
[webxperience2.netlify.app](https://webxperience2.netlify.app/)

## ✨ Unique Features
- **Fluid Cursor Interaction:** A custom cursor that adapts to its environment.
- **Parallax Product Cards:** Variable scroll speeds creating depth and immersion.
- **Dynamic Marquee:** A "System Optimized" continuously scrolling text ribbon.
- **Dark-Mode Aesthetic:** Deep blacks contrasted with vibrant crimson accents.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Custom Variables)
- JavaScript
- ScrollTrigger
