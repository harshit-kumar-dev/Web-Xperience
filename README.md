# /// Web-Xperience

A curated collection of high-impact, premium frontend web experiences. This project showcases advanced UI/UX concepts, modern animations, and immersive 3D interactions built with pure web technologies.

---

## [ Projects Showcase ]

### ◇ Task 1 : The Experience | Premium Portal
*Minimalist | Atmospheric | GSAP-Powered*

A sophisticated entry portal featuring a quad-quadrant interactive landing page. It uses architectural imagery and smooth transitions to create a cinematic web presence.

→ **Unique Features**: 
  - Dual-state image hover effects.
  - GSAP-driven "The Experience" entrance screen.
  - Dynamically clipped text overlays.
→ **Tech Stack**: HTML5, CSS3, JavaScript, GSAP.
→ **Directory**: `/task-1`

---

### ◇ Task 2 : FORGE | Elite Gym Gear
*Bold | High-Impact | Award-Nominated UI*

An aggressive, elite-grade fitness e-market website. Selected for its standout UI, this project focuses on high-contrast design, "The Forge" brand identity, and a focus on peak performance aesthetics.

→ **Unique Features**:
  - Custom fluid cursor interaction.
  - Parallax product cards with variable scroll speeds.
  - Dynamic "System Optimized" marquee.
  - Seamless dark-mode aesthetic with vibrant crimson accents.
→ **Tech Stack**: HTML5, CSS3 (Custom Variables), JS, ScrollTrigger.
→ **Directory**: `/task-2`

---

### ◇ Task 3 : AURA PRO | Pure CSS 3D
*Immersive | Interactive | 3D Storytelling*

A groundbreaking scroll-driven experience for the "AURA PRO" earbuds. This project features a complex earbud case modeled entirely in **Pure CSS 3D**, allowing for full rotation and interaction without external 3D libraries.

→ **Unique Features**:
  - Scroll-triggered 3D case opening and earbud reveal.
  - Complex CSS 3D transforms (faces, hinges, interior wells).
  - Immersive storytelling through vertical scrolling.
→ **Tech Stack**: HTML5, CSS 3D Transforms, GSAP, ScrollTrigger.
→ **Directory**: `/task-3`

---

## [ Core Technologies ]

● **Structure & Logic**: HTML5, JavaScript (ES6+)  
● **Styling**: Modern CSS3 (Grid, Flexbox, 3D Transforms)  
● **Animation Engine**: [GSAP](https://gsap.com/) & [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)  
● **Assets**: High-fidelity imagery from Unsplash and Google Fonts.

## [ Getting Started ]

To explore these experiences locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Web-Xperience.git
   ```
2. Navigate to any task folder:
   ```bash
   cd task-1 # or task-2, task-3
   ```
3. Open `index.html` in your browser.
