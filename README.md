## 🎯 Projects Showcase

### ✨ Task 1: The Experience | Premium Portal
> **Minimalist | Atmospheric | GSAP-Powered**

A sophisticated entry portal featuring a quad-quadrant interactive landing page. It utilizes architectural imagery and smooth, cinema-like transitions to establish a powerful web presence.

- **Dual-State Image Hover:** Interactive visual feedback on user engagement.
- **GSAP Entrance Sequence:** A meticulously timed, animated introduction.
- **Dynamic Text Overlays:** Clipped typography that interacts with the background.
- **Tech Stack:** `HTML5`, `CSS3`, `JavaScript`, `GSAP`

<br/>

### ⚡ Task 2: FORGE | Elite Gym Gear
> **Bold | High-Impact | Award-Nominated UI**

An aggressive, elite-grade fitness e-market interface. Designed with high-contrast aesthetics, "The Forge" brand identity emphasizes peak performance and premium quality.

- **Fluid Cursor Interaction:** A custom cursor that adapts to its environment.
- **Parallax Product Cards:** Variable scroll speeds creating depth and immersion.
- **Dynamic Marquee:** A "System Optimized" continuously scrolling text ribbon.
- **Dark-Mode Aesthetic:** Deep blacks contrasted with vibrant crimson accents.
- **Tech Stack:** `HTML5`, `CSS3` *(Custom Variables)*, `JavaScript`, `ScrollTrigger`

<br/>

### 🎧 Task 3: AURA PRO | Pure CSS 3D
> **Immersive | Interactive | 3D Storytelling**

A groundbreaking scroll-driven storytelling experience for the "AURA PRO" earbuds. The earbud case is modeled entirely in **Pure CSS 3D**, demonstrating the power of native web features without reliance on external 3D rendering engines like Three.js.

- **Scroll-Triggered 3D:** The earbud case naturally opens and reveals its contents as the user scrolls.
- **Complex CSS Transforms:** Intricate use of CSS 3D (faces, hinges, interior wells) to create a lifelike object.
- **Immersive Narrative:** Vertical scrolling dictates the pace of the visual story.
- **Tech Stack:** `HTML5`, `CSS 3D Transforms`, `GSAP`, `ScrollTrigger`

## 🛠️ Core Technologies

* **Structure & Logic:** `HTML5`, `JavaScript (ES6+)`
* **Styling Architecture:** Modern `CSS3` (Grid, Flexbox, Advanced 3D Transforms, Custom Properties)
* **Animation Engine:** [GSAP](https://gsap.com/) & [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)
* **Typography & Assets:** High-fidelity imagery (Unsplash) and premium typography (Google Fonts)

## ⚙️ Getting Started

Want to explore the source code and run these experiences locally? Follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/Web-Xperience.git
   ```

2. **Navigate into a specific task folder:**
   ```bash
   cd task-1 # Switch to task-2 or task-3 as needed
   ```

3. **Launch the project:**
   Simply open the `index.html` file in your preferred modern web browser.
   *(Tip: Use an extension like Live Server in VSCode for the best development experience!)*
